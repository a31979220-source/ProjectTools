# Project Workspace Rules

## Git Remote Push Rule
- Whenever the user asks to push code to remote ("把代码推上去" / "推送到远端"), **always push to all remote repositories (GitHub & Gitee)** simultaneously, unless the user explicitly specifies a single platform (e.g. "只推 GitHub" or "只推 Gitee").
- `origin` remote has been configured with dual push URLs for both GitHub (`https://github.com/a31979220-source/ProjectTools.git`) and Gitee (`https://gitee.com/zhangxiaokaiKAI/project-tools.git`).
